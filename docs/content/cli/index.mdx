# CLI

The FuneralAcademy CLI is the primary tool for deploying, managing, and developing FuneralAcademy. It orchestrates Docker Compose services and provides an interactive setup wizard for production deployments, as well as a full local development environment.

<img src="/img/pages/cli/cli-screenshot.png" alt="FuneralAcademy CLI" style={{ borderRadius: '12px', marginTop: '1rem' }} />

**Package**: [`funeralacademy`](https://www.npmjs.com/package/learnhouse) on npm

## Installation

### Quick Start (recommended)

```bash
npx funeralacademy@latest setup
```

### One-line Install (macOS / Linux)

Installs Docker, Node.js, and launches the CLI:

```bash
curl -fsSL https://raw.githubusercontent.com/learnhouse/learnhouse/main/apps/cli/install.sh | bash
```

### Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/learnhouse/learnhouse/main/apps/cli/install.ps1 | iex
```

## Requirements

- **Node.js** 18+
- **Docker** with Docker Compose v2

## What It Does

The CLI handles two main workflows:

### Production Deployment

The [setup wizard](/cli/setup-wizard) generates a complete Docker Compose deployment with:

- **FuneralAcademy app** container (Next.js + FastAPI)
- **PostgreSQL** database (with optional pgvector for AI)
- **Redis** cache
- **Caddy** or **Nginx** reverse proxy (with optional auto-SSL)

Each deployment gets a unique ID, allowing multiple instances on the same machine.

### Local Development

The [`dev` command](/cli/dev-mode) starts infrastructure in Docker and runs the API, web, and collaboration servers locally with hot reload.

## Quick Reference

| Command | Description |
| --- | --- |
| `npx funeralacademy setup` | Interactive setup wizard |
| `npx funeralacademy start` | Start all services |
| `npx funeralacademy stop` | Stop all services |
| `npx funeralacademy update` | Update to latest or a specific version |
| `npx funeralacademy status` | Show service status |
| `npx funeralacademy health` | Run health checks |
| `npx funeralacademy logs` | Stream container logs |
| `npx funeralacademy config` | Show installation info |
| `npx funeralacademy env` | Edit environment variables |
| `npx funeralacademy backup` | Backup database |
| `npx funeralacademy restore <archive>` | Restore database from backup |
| `npx funeralacademy doctor` | Run diagnostics |
| `npx funeralacademy deployments` | Manage deployments & resource limits |
| `npx funeralacademy shell` | Open shell in a container |
| `npx funeralacademy dev` | Start dev environment |
