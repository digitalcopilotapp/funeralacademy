# CLI Reference

Complete reference for all FuneralAcademy CLI commands. The CLI is published as `funeralacademy` on npm and is typically run via `npx funeralacademy@latest`.

## Setup and Configuration

### `funeralacademy setup`

Run the interactive setup wizard. This command generates `docker-compose.yml`, `.env`, `funeralacademy.config.json`, and nginx or Caddy configuration files based on your choices.

```bash
funeralacademy setup
```

Flags: `--ci`, `--name`, `--domain`, `--port`, `--admin-email`, `--admin-password`, `--channel <stable|dev>`, `--no-start`.

You can re-run this command at any time to reconfigure your instance. Existing configuration will be preserved as defaults in the prompts.

### `funeralacademy config`

View the current configuration.

```bash
funeralacademy config
```

### `funeralacademy env`

Interactively edit environment variables in your `.env` file (Domain & Hosting, Database & Redis, Security, AI, Email (Resend), S3 Storage, OAuth).

```bash
funeralacademy env
```

<Callout type="info">
The `env` command edits a curated set of variables only. SMTP credentials (`FUNERALACADEMY_SMTP_*`) are not editable through this command — edit `.env` directly if you need them.
</Callout>

## Service Management

### `funeralacademy start`

Start all FuneralAcademy services. On first run, this pulls the required Docker images before starting containers.

```bash
funeralacademy start
```

### `funeralacademy stop`

Stop all running FuneralAcademy services. Data is preserved in Docker volumes.

```bash
funeralacademy stop
```

### `funeralacademy status`

Show the status of each FuneralAcademy service.

```bash
funeralacademy status
```

### `funeralacademy logs`

Stream container logs for all services.

```bash
funeralacademy logs
```

### `funeralacademy update`

Update FuneralAcademy to the latest release or a specific version. Pulls the target image, rewrites `docker-compose.yml`, restarts services, and prompts for database migrations.

```bash
funeralacademy update
funeralacademy update --version 1.4.2
funeralacademy update --migrate       # auto-apply migrations
funeralacademy update --no-migrate    # skip migrations
```

### `funeralacademy dev`

Start a full development environment (PostgreSQL + Redis in Docker, API + web + collab run locally).

```bash
funeralacademy dev
```

## Diagnostics

### `funeralacademy doctor`

Run diagnostics on your FuneralAcademy installation. Checks Docker availability, container health, port conflicts, DNS resolution, and disk space.

```bash
funeralacademy doctor
```

### `funeralacademy health`

Run the CLI's health checks (PostgreSQL connection, Redis ping, HTTP health endpoint, disk, resources).

```bash
funeralacademy health
```

### `funeralacademy shell`

Open an interactive shell inside a running container for debugging.

```bash
funeralacademy shell
```

## Infrastructure

### `funeralacademy deployments`

Manage deployments and scale memory limits for your FuneralAcademy containers.

```bash
funeralacademy deployments
```

## Backup and Restore

### `funeralacademy backup`

Create a PostgreSQL dump archive of your instance's database (plus a copy of `.env`). Archives are written to `<installDir>/backups/`.

```bash
funeralacademy backup
```

### `funeralacademy restore`

Restore a database from a backup archive.

```bash
funeralacademy restore <path/to/funeralacademy-backup-<timestamp>.tar.gz>
```
