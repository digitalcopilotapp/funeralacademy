# Maintenance Overview

Keeping your self-hosted FuneralAcademy instance healthy requires periodic maintenance. The FuneralAcademy CLI provides built-in tools for the most common maintenance tasks.

## Maintenance Tasks

### [Updates](/self-hosting/maintenance/updates)

Keep FuneralAcademy up to date with the latest features, improvements, and security patches using `funeralacademy update`.

### [Backups](/self-hosting/maintenance/backups)

Protect your data with regular backups of the database and uploaded content using `funeralacademy backup`.

### [Monitoring](/self-hosting/maintenance/monitoring)

Monitor the health and performance of your instance using `funeralacademy status` and `funeralacademy logs`.

### [Troubleshooting](/self-hosting/maintenance/troubleshooting)

Diagnose and resolve common issues with your self-hosted instance.
